# Scripts de base de datos

Esta carpeta contiene guías para tareas locales de apoyo. El esquema de la aplicación se crea mediante migraciones Flyway en `backend/migrations/`, no con scripts manuales paralelos.

La URL, usuario y contraseña PostgreSQL se configuran fuera del repositorio (`SENIOR_MANAGE_JDBC_URL`, `SENIOR_MANAGE_DB_USERNAME`, `SENIOR_MANAGE_DB_PASSWORD`). No incluyas credenciales reales en scripts, semillas o documentación.
